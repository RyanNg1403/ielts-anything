# Gaps and measurement boundaries

- Cambridge 21 has four local Ppo Writing pages (W129–W132), but each Task 1 image is explicitly missing from the supplied text corpus. The four CSV rows are retained with blank visual fields and are excluded from Task 1 family counts and density calculations. Cambridge 21 Task 2 prompt text is present and included in the 40-prompt counts.
- Process-stage counts are directly numbered on five of seven process pages. The hydroelectric page (Cambridge 14 Test 3) and cyclic ethanol page (Cambridge 19 Test 3) have no numbered stage sequence; their stage counts are labelled “estimate” in the ledger, based on distinct labelled flow steps.
- Map feature counts are counts of distinct labelled semantic feature classes across both states, counting a class once even when it repeats (for example, several seating labels). Compass marks, state/date captions and key symbols are excluded. Classification of a compound label as one class is a measurement convention.
- Table rows sum the data rows across tables in one stimulus, excluding header rows. The columns field records the largest column count among its tables, including the row-label column. This makes the three-table New York example comparable without copying any cell values.
- For mixed stimuli, categories count labelled chart groups or pie segments, not table labels; time_points count labelled years/months; rows sum table data rows; cols give the widest table; series count chart series or separate pies. These fields describe component density and should not be summed as chart data.
- Cambridge 12–19 source_page values are printed page numbers visible on the inspected Writing pages. Cambridge 20 uses stable PDF scan-page indices as specified in corpus.md; Cambridge 21 uses Ppo Writing IDs.
- I did not use web fetches: the requested visual conventions were observable in the local Cambridge pages. No claim is made about conventions absent from this sample beyond what the inspected pages show.
- The observed densities are sample measurements from Cambridge 12–20, not universal generator quotas. Some visual labels are faint in the source scans; only structural counts were recorded, never plotted values.
