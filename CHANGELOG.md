# Changelog

## 0.0.1

First release. Run it with `npx ielts-anything`.

- Cambridge-format IELTS Academic practice on any topic, written and checked by your Codex subscription.
- Reading: full tests and drills, every question type, an independent solver pass, review with passage evidence.
- Listening: four recorded parts with narrator and preview pauses, forms and maps, exam and practice modes, review with transcript and jump-to-answer audio. Voices from Kokoro (free, local) or OpenAI (your API key).
- Writing: Task 1 charts, tables, maps and process diagrams, Task 2 essays, marked against the official descriptors.
- Speaking: a live voice examiner for Parts 1-3, marked against the official descriptors.
- Chat tutor, test library, progress tracking, light and dark themes.
